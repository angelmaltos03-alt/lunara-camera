# Contributing to LUNARA

Thanks for your interest in LUNARA.

## Workflow
1. Open an issue describing the bug or proposed feature.
2. Fork the repository and create a focused branch.
3. Keep changes small and document device-specific behavior.
4. Run available tests and build with Xcode before opening a pull request.
5. Include iPhone model and iOS version for camera-related reports.

## Safety and privacy
Never commit API keys, signing certificates, provisioning profiles, private photos, or personal credentials. Cloud processing must be opt-in and must clearly explain what image data is sent.

## Moon photography
Do not add synthetic lunar surface detail and represent it as captured fact. Clearly distinguish optical detail, computational enhancement, and generative output.
