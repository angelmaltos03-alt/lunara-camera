Lumen Camera was consulted as an architectural reference for a reusable image-development pipeline, adjustable filter intensity, and the approach of using a common image-processing path for preview and full-resolution captures.

The current LUNARA AUTO/PRO editor is implemented in LUNARA's own source files. The live Metal preview from Lumen is not included in this branch; it remains a future integration stage.
